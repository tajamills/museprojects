# abisolawrites — deploy notes

Rebuild of abisolawrites.com (The Abisola Writes Library) off Emergent,
mirroring the other museprojects apps: Node 20 + Express + React 19 +
Tailwind v4, esbuild bundles, multi-stage Dockerfile.

## Railway setup (owner steps)

1. New service in the museprojects project, source repo `tajamills/museprojects`,
   **Root Directory: `abisolawrites`**.
2. Variables:
   - `SITE_URL` — the public URL (Railway domain first, `https://abisolawrites.com` after DNS).
   - `DATABASE_URL` — **owner step, needed for durable accounts/entitlements:**
     add a Postgres database to this Railway service (Add → Database →
     PostgreSQL) and reference its `DATABASE_URL` variable here. Without it
     the server falls back to a local file store, which Railway can wipe on
     redeploy — lifetime book entitlements must live in Postgres.
   - `STRIPE_SECRET_KEY` — when ready to take payments. Until set, all buy/book
     buttons land on the honest "checkout is being reconnected" notice.
   - `STRIPE_WEBHOOK_SECRET` — after creating the webhook endpoint
     `{SITE_URL}/webhooks/stripe` in the Stripe Dashboard (event:
     `checkout.session.completed`). The webhook is what grants a buyer's
     book entitlement after payment.
   - `ADMIN_TOKEN` — optional; when set, enables `POST /api/admin/grant` and
     `/api/admin/revoke` (Bearer token) for manual entitlement grants, e.g.
     honoring a buyer from before the move.
   - `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` — later, if Google sign-in
     is ever connected. Email sign-in is the live system (see below);
     `/auth/google` redirects to `/signin` until then.
   - `PORT` is injected by Railway automatically.
3. Accounts + entitlements (built Oct 27, 2026): email sign-up/sign-in with
   scrypt-hashed passwords and server-side sessions; a completed Stripe
   checkout grants a **lifetime** entitlement for the purchased book, keyed
   to the buyer's account (email fallback). Chapter text is served by the
   server only — free chapters publicly, paid chapters to entitled
   accounts — and is never in the client bundle.

## DNS cutover (registrar — owner step)

Point the domain at the Railway service (Railway → service → Settings →
Networking → Custom Domain gives the exact CNAME/A target). Verify the new
site live on the Railway domain first; cancel Emergent only after the custom
domain serves the new build.

## Local run

```sh
npm install
npm run build
npm start          # http://localhost:3000
# or dev-style: PORT=3100 node dist/server.js
```
